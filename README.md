# Flag Guessr

A flag identification game. You're shown a country's flag and given four options — pick the right one and keep your streak alive. One wrong answer ends the run.

## Features

- Streak-based scoring with a persistent high score
- Difficulty settings (easy / normal / hard) that affect how similar the wrong options are
- Region filter to focus on a specific part of the world
- Round history shown on the game over screen

## Stack

React + TypeScript, built with Vite.

## Running locally

```bash
npm install
npm run dev
```
